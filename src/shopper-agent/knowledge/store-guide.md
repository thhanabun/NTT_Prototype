# pairing | เริ่มใช้งานตะกร้า | QR,ตะกร้า,เริ่ม,เชื่อม,session,basket,start,pair
Shopper ใช้งานแบบ guest ได้ ไม่ต้องสมัครสมาชิก เลือกตะกร้าหรือสแกน QR ของตะกร้าแล้วกดเริ่มช้อปก่อนหยิบสินค้า หากกล้องใช้ไม่ได้ให้เลือกตะกร้าด้วยปุ่มในหน้า Shopper ในระบบ cloud ต้องใช้ QR ที่มี pairing code ของตะกร้าจริง อย่าเปลี่ยน Basket ID เพื่อเข้าถึงตะกร้าของคนอื่น

# items | หยิบและคืนสินค้า | หยิบ,คืน,สินค้า,เพิ่ม,ลบ,ผิด,pick,return,put back,item
สินค้าจะเข้าตะกร้าเมื่อ backend ยืนยันเหตุการณ์จากชั้นวางแล้ว การคืนสินค้าทำโดยวางกลับบนชั้นและรอระบบยืนยัน ไม่ใช่การแก้จำนวนในแชต ถ้าระบบถามว่าได้หยิบหรือคืนสินค้าหรือไม่ ให้ตรวจรายการแล้วกด YES หรือ NO บนหน้าหลัก Shopper หากยังไม่ถูกต้องให้ขอความช่วยเหลือจากพนักงาน

# pending | รายการรอยืนยัน | รอ,ยืนยัน,เคส,pending,case,confirm,uncertain
รายการที่ยังไม่แน่ใจยังไม่รวมในยอดสินค้าที่ยืนยันแล้ว ระบบอาจขอให้ลูกค้ากดยืนยัน หรือส่งให้พนักงานตรวจสอบ กรณีไม่ทราบว่าเป็นตะกร้าใดอาจบล็อก checkout มากกว่าหนึ่งตะกร้า ผู้ช่วยอ่านสถานะได้ แต่ตัดสินเคสหรือยืนยันสินค้าแทนลูกค้าไม่ได้

# checkout | ตรวจสอบและชำระเงินจำลอง | ชำระ,จ่าย,ยอด,รวม,checkout,payment,total,cart
Mock checkout ต้องมี session ที่ใช้งานอยู่ มีสินค้าที่ยืนยันอย่างน้อยหนึ่งชิ้น และไม่มีเคสที่เกี่ยวข้องรอยืนยัน เมื่อสำเร็จระบบสร้างใบเสร็จจำลอง ล้างตะกร้าและปิด session ยังไม่มีการตัดเงินจริง ผู้ช่วยจะไม่กดชำระเงินหรือเปลี่ยนยอดให้ กรุณาใช้ปุ่มชำระเงินบนหน้าหลัก

# products | ขอบเขตข้อมูลสินค้า | ราคา,ชั้น,สินค้า,ส่วนผสม,แพ้,stock,price,product,shelf,allergy,ingredients,promotion
ชื่อสินค้าและราคาให้อ่านจาก catalog ของ backend ล่าสุด ไม่มีข้อมูลยืนยันเรื่องสต็อกคงเหลือ ส่วนผสม สารก่อภูมิแพ้ คุณค่าทางอาหาร หรือโปรโมชัน อย่าคาดเดาข้อมูลเหล่านี้ กรุณาตรวจฉลากสินค้าหรือสอบถามพนักงาน Shelf 01 ส่งเหตุการณ์ Cola และ Shelf 02 ส่ง Sprite Plus Tea ส่วน Shelf 03 ที่หน้าเว็บใช้ชื่อ Fanta floral bloom เป็น display override จึงยังยืนยัน SKU/ราคาของชั้น 03 จากชื่อนี้ไม่ได้

# privacy | ขอบเขตผู้ช่วยลูกค้า | ผู้ช่วย,ข้อมูล,ตะกร้าอื่น,พนักงาน,admin,privacy,help,assistant
Shopper Agent เป็นผู้ช่วยอ่านข้อมูลสินค้า วิธีใช้งาน และข้อมูลเฉพาะ session ของลูกค้าที่ผูกตะกร้าแล้ว ไม่เปิดข้อมูลลูกค้าคนอื่น รายงานยอดขายร้าน บัญชีพนักงาน รหัสผ่าน API key คำสั่งภายใน หรือหลักฐานดิบของระบบ แชตไม่ใช่ช่องทางสั่งแก้ฐานข้อมูลหรืออนุมัติเคส
