# Test scenarios for the store-map tracking page

Source: public research datasets with published floor calibration (EPFL CVLab multi-camera pedestrians, WILDTRACK). All research-use only; see `licence`. Videos: `videos/<id>/cam<N>.webm`, truth: `videos/<id>/truth.json` (per camera image->floor homography in metres for the OUTPUT video pixels, time offsets, GT positions where the dataset has them). Full machinery: `tools/` (build.py, make_scenarios.py, verify.py, finalize.py). Floor-reference hints describe what is visible; no pixel coordinates.

Metric scale caveat: EPFL gives no unit for most sequences; `floor_unit_m` is an estimate (+/-30 %), homography truth is exact up to that scale. WILDTRACK is exact metres.

Terrace scale (B1-06, B1-08, B2-13; EPFL Terrace 1/2): 1 unit = 1.82 cm, i.e. the earlier 0.86 cm estimate x 2.12. Basis: people measured on the page came out 0.8 m tall, so the scale was set so that people are ~1.7 m. Treat metres there as +/-30 %. Lab scenarios keep 3 cm/unit (people come out ~2.8-3.0 m there: errors look larger, the safe side).
