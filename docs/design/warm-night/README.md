# FAST — Warm × Night design

Design source exported from Claude Design (clickable prototypes, Thai UI). Not wired to the real app yet.

- `Main` design system (day + night palettes, type, components)
- `Shopper` phone app prototype: login/Guest, scan, confirm pick/return, checkout, receipts, profile, help
- `ShopperDay` / `ShopperNight` all 15 phone screens per mode
- `Admin` dashboard + floating Laya chat + result tabs, case review with camera clip and Basket A/B answer
- `AdminLogin` staff login

Night mode uses warm orange (no neon). Clip player and sample data are mock only.
Open the `.dc.html` files in Claude Design; `canvas.json` holds the board layout.

The earlier five explorations live in `web/src/app/design/` (Next.js routes under `/design`).
